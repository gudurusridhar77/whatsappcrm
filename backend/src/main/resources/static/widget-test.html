Live Chat Widget Test Page

This page demonstrates the embeddable live chat widget for the WhatsApp CRM platform.

Setup Instructions

  1. Make sure the backend is running on http://localhost:8080
  2. Create a Web Widget inbox in the CRM dashboard (Inboxes → + New Inbox → Web Widget)
  3. Copy the inbox token from the inbox detail panel
  4. Paste it below and click Load Widget

Sample Content

This is a sample website page. The chat widget appears as a floating button in the bottom-right corner.

Click the chat bubble icon to open the widget, enter your name and message, and start chatting with the support team!

Features of the widget:

  • Customizable colors matching your brand
  • Optional pre-chat form (name & email)
  • Real-time message delivery (3-second polling)
  • Persistent sessions across page refreshes
  • Mobile responsive design
  • Greeting message support
Note: In production, you would embed the widget script directly in your website's HTML instead of using this test page. See the Inboxes page for the embed code snippet.
